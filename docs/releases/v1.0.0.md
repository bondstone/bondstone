## Highlights

- The engine is rebuilt on the accepted design: profiles, packs, bridges and presets, with
  severities `error`, `warn`, `info` and `ignore`.
- `bondstone check --base REF` checks lifecycles, immutability and diff rules against a
  commit, with exemptions declared in commit trailers.
- Commands for agents: `context`, `rules`, `explain`, `new`, `status`, `supersede`, `agent`
  and `graph`.
- The pack library is a separate package, `bondstone-library`, with `adr`, `capability`,
  `speckit`, `cli` and `release`, their bridges and the presets `starter` and
  `starter-speckit`.
- Spec Kit features are part of the graph, with a status taken from their files.
- Matrix views and link columns in tables.
- Packs, bridges and presets can come from git sources, pinned by commit and hash in
  `.bondstone/bondstone.lock`; `bondstone update` is the only command that uses the network.
- `bondstone report`, `bondstone waive` and SARIF output for `check`.
- Known violations: `bondstone baseline --known` records the problems a repository has when it
  adopts a rule, so that only new ones fail; the record can only shrink.
