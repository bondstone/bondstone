## Highlights

- Engine with packs, bridges, traits, roles, diff checks, views and code traceability.
- Built-in packs `adr`, `ost`, `capability`; bridges `ost-capability`, `adr-capability`.
- `bondstone supersede`, strict creation statuses and traced diff rules.
- Bondstone documents itself (CHG-001), including its CLI (CHG-004).
- Baselines for adopting bondstone in existing repositories (CHG-002).
- `covered` selector and region-based tracing (CHG-003).
